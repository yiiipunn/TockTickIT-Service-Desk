AI helped me break the eleven-page Lab 4 assignment into smaller issues and connect requirements to implementation and tests. The specification agent organized the contract, while coding assistance supported the migration, APIs, interfaces, dashboards, and browser checks. I used the assignment and approved specifications as scope boundaries. The recorded history-refresh correction in Issue #31 reminded me that generated code can look complete while an integrated screen still behaves incorrectly. Passing unit tests alone was therefore not enough; the recorded regression and E2E runs, genuine screenshots, and DEV4952’s approvals gave stronger evidence. Those approvals show that review happened, but they do not prove every manual check or replace my own understanding. The current documentation follow-up also showed why Git authority must remain clear: a feature-branch push needs an audit after its original PR has merged. Next time, I would give AI smaller tasks tied to acceptance criteria, inspect each diff, test with isolated data, capture evidence early, and record what I personally checked.
